CURRENT MIGRATION DECISIONS
============================================================

- Main.tscn remains the composition root.
- WheelDisplay.tscn is reused six times.
- WheelUi owns logical wheel numbering.
- Buy/Upgrade windows receive wheel identity; they do not calculate it independently.
- CenterUi is a Control Node, not a scene.
- StatisticsWindow contains Graph1, Graph2 and Graph3 as child Nodes.
- Shared visual configuration remains in Scripts/global/UiSettings.cs.
- Runtime UI creation is removed only after the equivalent scene-based implementation is verified.
- Simulation/gameplay code must not be changed as part of UI migration unless required to remove obsolete UI construction.
- Old WheelPurchaseUi and WheelUpgradeUi remain temporarily because runtime verification of the new scene-based windows has not yet been performed.
