- Position the button consistently with the existing HUD.
- Make the button visually match the rest of the UI.
- Connect the button to opening/closing the graph.
- Prepare the button for integration with the central UI state system.

Acceptance criteria

- Graph button is visible in the correct HUD position.
- Button uses the existing pixel-art UI style.
- Pressing the button opens/closes the graph.
- Button does not interfere with other HUD controls.

5. Tilt System

«Dependency: The settings window must exist before tilt settings can be implemented.»

5.1 Implement tilt settings

Add tilt configuration to the settings panel.

Tasks

- Add a tilt-angle control.
- Use a slider ranging approximately from -45° to +45°.
- Display the current angle if appropriate.
- Provide a way to return to neutral tilt.
- Store the selected value in the appropriate settings/state system.

Acceptance criteria

- Player can change the tilt angle from the settings panel.
- The selected value is correctly stored.
- Neutral tilt can be restored.

---

5.2 Implement tilt mechanics

Connect the configured tilt angle to the fluid simulation.

Tasks

- Add a tilt button to the HUD.
- Add the directional arrow using "idle-water/pixelbuttons/00.png".
- Convert the selected angle into a gravity direction vector.
- Pass the modified gravity direction to the fluid solver.
- Update the simulation when tilt changes.
- Ensure neutral tilt produces normal downward gravity.

Acceptance criteria

- Water flows in the expected direction when tilted.
- Changing the tilt updates the simulation correctly.
- Neutral tilt restores normal gravity.
- HUD tilt controls correctly reflect the current state.

11. Simulation Stability

11.1 Fix water still accumulating somewhere

Diagnose and resolve the persistent water accumulation bug.

Investigation

Temporarily render the water simulation in front of the other textures so accumulation areas are easy to identify.

Investigate possible causes such as:

- Boundary leaks
- Particles becoming permanently stuck
- Sleep logic failing to wake particles
- Pixel occupancy errors
- Grid off-by-one errors
- Collision edge cases
- Particles becoming trapped around wheels
- Particles getting stuck against environment geometry

Acceptance criteria

- No unexplained water deposits continue growing.
- A long-running simulation remains stable.
- The fix does not introduce new fluid or collision problems.
