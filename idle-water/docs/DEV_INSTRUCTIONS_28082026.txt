============================================================
2. MIGRATION RULE
============================================================

Migrate one logical component at a time.

For every component:

1. Inspect the current script and the existing Godot scene hierarchy.
2. Identify which Nodes already exist in the scene.
3. Change the script so it controls those Nodes instead of constructing duplicate UI at runtime.
4. Preserve the existing behavior.
5. Test/compile before moving to the next component.
6. Only then remove obsolete runtime construction.
7. Update docs/UI_PASS_2_MIGRATION_PROGRESS_28082026.txt.

Do NOT delete a legacy script merely because it is marked:
// THIS FILE SHALL BE GONE SOON //

The marker means the file is intended for eventual removal. Remove it only after all of its responsibilities have been migrated and all references are gone.
